# New Client Onboarding

> This is an example showing the format. Delete it once you have real files.

## When to use this

Use this playbook after a client approves the work and both sides are ready to begin. The project lead owns the process.

## Before you start

Confirm the agreed scope, start date, billing status, and best shared channel. Resolve any gap before scheduling kickoff.

## Steps

1. Confirm the agreement is complete and the start date still works.
2. Send the welcome message with one shared channel for questions.
3. Create the project workspace under an internal project ID.
4. Schedule kickoff with a short agenda and any preparation needed.
5. Build a first-week outline with owners and due dates.
6. Share the outline, then invite corrections before work begins.
7. Record kickoff decisions in the project workspace.

## Done when

- The client knows what happens next and where to ask questions.
- The team can see the goal, scope, owners, and first deadlines.
