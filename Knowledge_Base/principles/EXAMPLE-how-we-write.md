# How We Write

> This is an example showing the format. Delete it once you have real files.

We write for a person who has something else to do. The point should be clear on the first read, and the next action should be easy to spot.

- Lead with the useful answer.
- Keep sentences short when the subject gets complicated.
- Name concrete dates, owners, and actions when they matter.
- End with the decision or next step.

Warmth comes from attention, not filler. We sound calm and direct, and we say when we don't know something.
